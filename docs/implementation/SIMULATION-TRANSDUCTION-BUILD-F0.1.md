## Contract and six artifacts

1. **Generative Chamber Boundary.** Formation accepts bounded supplied model-dependent possibilities. It has no store, adapter, token issuer, grant constructor, network client, or installation interface. No quantum or AI provider is added. Formation records do not enter native occurrence/receipt slots.
2. **SimulationArtifact.** An immutable typed possibility binds an ID, exact decision context, model/version/settings/input references, prediction, assumptions, uncertainty, missing information, and instrument limitations. It has authority effect `none`, epistemic status `MODEL_DEPENDENT_POSSIBILITY`, occurrence status `NOT_OBSERVED`, and evidence status `NOT_ADMITTED`.
3. **Decision-equivalence compression.** Relative to a declared context K_d, only exact equality of all declared burdens, assumptions and instrument limitations permits grouping. Required burdens: proposed disposition, authority requirement, material risk, irreversibility, uncertainty disclosure, dependency requirements, Return burden, benefit, and alternatives. UNKNOWN or CONFLICTING cells stay distinct even when their wording matches. Raw artifacts and class membership remain bound and reconstructable. This is conservative declared-burden equivalence, not a proof that arbitrary narrative differences are irrelevant.
4. **Rasmussen transduction contract.** Pure transduction produces only a PassageCandidate, represented as content of the existing canonical `recommended_action` candidate. It preserves the complete simulation set, context, compression, selected class, assumptions, missing information, metrology, provenance and alternatives. Transduction does not adjudicate.
5. **RIO proposal surface.** Purpose, benefit, risk, uncertainty, alternatives, irreversibility, dependencies, expiry and Return burden become an inspectable decision surface on the existing policy input and decision records. The existing root-signed field dependency `simulation-transduction-f0.1` pins the current implementation and requires this formation boundary regardless of a model's tag. A current root-signed formation review binds its exact surface and requested operation. Review is not an action grant. The existing grant, RIO policy and point-of-use Sentinel checks remain separately required. This slice does not implement a new semantic risk assessor.
6. **Non-conversion conformance.** Simulation cannot type-check as Evidence, Occurrence, Authority or an execution token. The existing Relation Compiler rejects simulation artifacts at Direct's consequential edge. Public runtime tests must refuse fabricated authority, stale/revoked grants, mismatched subjects and changed operations.

## Enforcement boundary and limits

Compromised reasoner != compromised authority within the accepted LocalField and HTTP path: arbitrary supplied generative content cannot manufacture a current signed grant, pass policy by declaring ADMIT, issue/burn an execution token, or call the private adapter release. This is not a whole-host compromise-containment claim.

Compression preserves the declared decision burden. Incorrect or omitted real-world burdens cannot be detected from declarations alone; the complete raw inputs, missing-information cells and metrology limits are retained for review. A review signature is attribution, not proof of correct predictions or informed consent in every domain.

Development acceptance uses synthetic declared possibilities and an actual create-only report file in a temporary sandbox. It proves the runtime integration, not simulator accuracy, relational capability, a quantum result or a comparative HLSI assay.
