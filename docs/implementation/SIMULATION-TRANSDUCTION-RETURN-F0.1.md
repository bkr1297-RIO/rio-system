## Interfaces and bounds

The existing `gateway/local-field/relations/index.mjs` exports `DecisionContext(value)`, `SimulationArtifact(value)`, `compressPossibilities(context, artifacts)` and `transducePossibilities({context, artifacts, compression, selected_class_id, human_review})`. These return immutable formation objects. Transduction returns PassageCandidate content without an authority basis or execution permit. Existing LocalField candidate storage, configuration, grants and dispatch APIs remain the runtime entry points.

The native guard reconstructs the entire candidate, matches its source, question and exact requested operation, and verifies an attributable formation review using the existing `{body, signature}` owner. Review binds the context, compression, selected class, decision surface and request. It neither grants action standing nor changes policy. Current candidate, review, field configuration, dependencies, node standing and grant checks are rerun at the consequential crossing. Historical Return reconstruction does not regenerate permission.

K_d requires disposition, authority requirement, material risk, irreversibility, uncertainty disclosure, dependency requirements, Return burden, benefit and alternatives. Cells are KNOWN, UNKNOWN or CONFLICTING. Correctness and completeness of a declared burden are outside this validator's scope. Different prediction narratives may group only under this declared-burden contract; the original narratives and membership remain reconstructable.

Limits remain explicit: 32 artifacts; 16,384 bytes per artifact; 32,768 bytes per set; 49,152 bytes per candidate; 8,192 bytes per prediction; 4,096 bytes per actual output. The existing adapter limit is unchanged. The report omits repeated member/provenance hash lists, binds the full retained decision surface by hash, and preserves every alternative's declared burden. A report exceeding the limit is refused instead of dropping a burden. Native transport and Return limits remain enforced.

Failures reuse existing thrown error semantics: malformed context/artifacts or forbidden conversions; COMPRESSION_CONFORMANCE; SIMULATION_PASSAGE_BINDING; SIMULATION_REVIEW_REQUIRED; SIMULATION_NOT_CONFIGURED; SUBSTRATE_DRIFT; SIMULATION_RESOURCE_LIMIT; and existing authority, dependency, policy, fidelity, replay and Return-proof refusals. No parallel permission or error subsystem is added.
